## 🎯 시나리오 12개 (실 데이터 + NEXUS 실 처리)

### 시나리오 1. 매출 데이터 분석 (raw → 인사이트)
```
사장님: "바탕화면 매출 엑셀 분석해줘"
NEXUS 가 해야 할 것:
  ✅ 매출_뒤죽박죽_2025.xlsx 자동 발견
  ✅ raw 100건 + 분기별 시트 읽기
  ✅ 인사이트 추출 (Q3 부진, Q4 회복, 채널별 마진)
  ✅ 카드: excel_analyze (요약 + 차트 + 권장 액션)
검증: 답변에 실제 숫자 (145M/168M/152M/198M) 포함되는가?
```

```
  ✅ 독소조항 10개 추출:
     - 1개월 일방 해지
     - 무제한 배상 (영업비밀)
     - 매출 5% 위약금
     - 5년 NDA + 위약벌 1억
     - 2년 경업금지 + 전액 반환
  ✅ 페르소나 자동: legal → contract_review 액션
  ✅ 카드: 위험도 표시 + 수정 제안
검증: "1억", "5%", "5년" 등 실 숫자 인용?
```

### 시나리오 7. 멀티 액션 분해
